# CoolCoach

Мобильное / веб-приложение-ассистент для контроля качества выполнения физических упражнений с использованием компьютерного зрения и машинного обучения.

## Команда и ветки

| Роль | Ветка | Зона ответственности |
|------|-------|----------------------|
| Frontend | `frontend` | UI, камера, отображение обратной связи, дашборд |
| Backend | `backend` | FastAPI, WebSocket, БД, auth, API, деплой |
| AI / CV | `ai-model` | MediaPipe, анализ позы, логика упражнений, LLM-фидбек |

Базовая ветка: `main`. Работу ведём в своих ветках и объединяем через Pull Request.

## Планируемый стек

- **Frontend:** веб-клиент с доступом к камере
- **Backend:** Python, FastAPI, WebSocket, PostgreSQL
- **AI:** MediaPipe (pose estimation), логика углов/повторов, LLM для текстовых подсказок
